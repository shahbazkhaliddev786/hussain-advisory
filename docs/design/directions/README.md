# Design directions (milestone 1)

Source of the artboards on the Claude Design canvas "PASA Design Directions".
They are Design Component files: static HTML with inline styles, plus a small
script for the interactive procurement-cycle selector. Open them on the canvas;
they rely on the canvas runtime (`support.js`) and its uploaded logo assets.

| File | What it shows |
|---|---|
| `Main.dc.html` | Direction A, full homepage (recommended) |
| `A-Phone.dc.html` | Direction A on a phone |
| `A-Dictionary.dc.html` | Direction A, Knowledge Hub dictionary entry |
| `A-Style.dc.html` | Direction A style tile: color, type, components |
| `B-Home.dc.html` | Direction B, the workbook: homepage opening |
| `C-Home.dc.html` | Direction C, institutional: homepage opening |
| `Structure.dc.html` | Proposed site structure |

Placeholders: the portrait of Naeem Abbas, training dates, format, duration and fee.
Copy is drafted from `docs/brief/client-brief.md` and needs the client's review.
